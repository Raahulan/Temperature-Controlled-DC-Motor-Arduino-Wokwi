# Upload to GitHub

**Repository name:** `Temperature-Controlled-DC-Motor-Arduino-Wokwi`

**Description:** `Arduino UNO temperature-based PWM control using an NTC thermistor, LED output indication, serial monitoring, and Wokwi simulation.`

1. Download and extract the project ZIP.
2. Go to https://github.com/new and create a **Public** repository with the name above.
3. Leave the GitHub-generated README/LICENSE options unchecked, because these files already exist.
4. In the empty repository select **uploading an existing file** (or **Add file → Upload files**).
5. Select and upload **all files and directories inside** the extracted folder; do not upload just the ZIP.
6. Enter commit message: `Initial commit - Temperature Controlled PWM Wokwi simulation`.
7. Click **Commit changes**.
8. Confirm that `README.md` is visible on the repository homepage and images display correctly.
9. Optionally add repository topics: `arduino`, `wokwi`, `temperature-sensor`, `thermistor`, `pwm`, `embedded-systems`.

To simulate, open https://wokwi.com/projects/new/arduino-uno and paste in the project's `sketch.ino` and `diagram.json`.
